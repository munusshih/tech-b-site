## Lecture: Setup, Draw, and System Thinking

This opening lecture introduces the course rhythm, establishes a reliable p5.js workflow, and moves from a single drawing toward a small generative system.

### Learning Goals

- Understand the course rhythm and project expectations.
- Set up a reliable p5 workflow for weekly sketching.
- Move from one static output toward a small generative system.

### Class Flow

1. Course framing and examples.
2. p5 setup and first drawing.
3. Variables and loops for variation.
4. Making workshop, critique, and assignment briefing.

### Starter Sketch

```js title="Starter Sketch"
function setup() {
  createCanvas(640, 420);
  background(245);
  noLoop();
}

function draw() {
  fill(25, 40, 90);
  circle(width * 0.5, height * 0.5, 160);
}
```

### Variation Pattern

```js title="Variation Pattern"
function draw() {
  background(250, 245, 236);
  noStroke();

  for (let i = 0; i < 40; i += 1) {
    const x = random(width);
    const y = random(height);
    const d = random(8, 40);
    fill(20, 30, 60, 120);
    circle(x, y, d);
  }
}
```
