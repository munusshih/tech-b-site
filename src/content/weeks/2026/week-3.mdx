tldr: |
  When does a simple set of rules begin to look like behavior?

  <br><br>

  This week, we will move from **representation to simulation**. A model never reproduces the world completely. It selects certain relationships, states, differences, and behaviors and treats them as sufficient. By studying random walks, automata, cellular systems, flocking, collective behavior, and other simulations, we will ask what a model preserves, what it leaves out, and why we nevertheless recognize its behavior as meaningful, lifelike, or intelligent.

Return to the small working model you built last week. This week, make **two versions of the same underlying system** to study how representation and interface affect the way its behavior is interpreted.

In the first version, make the mechanism legible. Let someone see the categories, rules, decisions, inputs, or transformations that produce the output. For instance, you might show the state of the system at each step, display the rules that govern its behavior, or provide a way to trace how one input leads to another output. The goal is to make the underlying logic of the system clear and understandable.

In the second version, keep the underlying logic substantially the same but hide the mechanism. Make the system appear to behave intelligently, lifelike, or meaningful without revealing how it works. You might use a more abstract interface, a different set of symbols, or a more complex surface that obscures the underlying rules. Could you make the system appear to have a mind of its own, even though it is still following the same rules as the first version? Could you make it "think", or "feel", or "decide" in a way that seems more human, even though it is still a simple set of rules?

The goal is not simply to make the second version more polished. Use the pair to ask what changes when a designed surface performs qualities the underlying mechanism may not possess. Document both versions and compare them.

Bring both versions, your documentation, observations, and question to class next week. We will use them to prepare for the imitation game and consider how an audience might evaluate a system from its behavior alone.
